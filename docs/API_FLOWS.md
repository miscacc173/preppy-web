
## Admin promotions and referrals oversight

System administrators can review all institute-owned promo codes, referral activity, reward promo codes, and promotion redemptions from Admin > Billing & plans > Promotions & referrals. Filters include institute, status, code, student name/email, and date range. The view supports CSV export and admin-only activation/deactivation of institute promo codes. Existing institute promo ownership and successful-payment redemption rules remain unchanged.
